Labels the instrument class. Each class has a fixed accent color (also used for allocation charts via `assetColor(type)`).

```jsx
<AssetTypeBadge type="etf" />
<AssetTypeBadge type="future" size="sm" />
```

Types: stock, etf, fund, bond, future, option, crypto, cash. Import `assetColor(type)` to color chart segments consistently.
