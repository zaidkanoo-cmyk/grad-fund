The "should we invest?" answer, in one pill. Use on detail headers and screener rows.

```jsx
<VerdictPill verdict="buy" />     // INVEST (green)
<VerdictPill verdict="watch" />   // WATCH (amber)
<VerdictPill verdict="avoid" />   // AVOID (red)
```

Distinct from HalalBadge — verdict is the investment call, halal is the compliance check; show both.
