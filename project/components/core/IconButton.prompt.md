Square icon-only button — toolbars, table-row actions, close/expand controls. Always pass a `label` for accessibility.

```jsx
<IconButton label="Add to watchlist" variant="outline"><StarIcon size={16}/></IconButton>
<IconButton label="More" variant="ghost"><MoreIcon size={18}/></IconButton>
```

Variants: `ghost | outline | solid`. Sizes `sm | md | lg`.
